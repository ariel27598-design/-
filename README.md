# שולחן משחקים 🎲

אפליקציית ווב למציאת משחק הקופסא המושלם: סורקים ברקוד, עונים על שאלון קצר (לבד או כקבוצה), ומקבלים המלצה מדורגת מתוך ספריית המשחקים שלכם.

## תכונות

- **סריקת ברקוד** - סריקה מהמצלמה (או הזנה ידנית) שמאתרת משחק בספרייה לפי הברקוד שלו.
- **שאלון התאמה אישי** - כמה שאלות קצרות (זמן פנוי, מורכבות, מזל מול אסטרטגיה, שיתופי/תחרותי, סגנונות מועדפים) שמדרגות את כל המשחקים לפי מידת ההתאמה.
- **מצב קבוצתי** - כל משתתף ממלא את השאלון בתורו, והאפליקציה מוצאת את המשחק עם ההסכמה הגבוהה ביותר בין כולם (לא רק הממוצע - גם מי שחושב אחרת מקבל משקל).
- **ספרייה מלאה** עם סינון לפי "ברשותי / לא ברשותי", קטגוריה, שיתופי/תחרותי וחיפוש חופשי.
- **הוספת משחקים חדשים** - שם, ברקודים, תמונה (URL או העלאת קובץ), הסבר קצר, קישור לסרטון הסבר, וכל מאפייני ההתאמה (שחקנים, זמן, גיל, מורכבות, מזל/אסטרטגיה, קטגוריות).
- **עמוד משחק** עם תמונה, הסבר, הטמעת סרטון יוטיוב (כשמזוהה קישור תקין) וכל הנתונים.

כל הנתונים נשמרים מקומית בדפדפן (localStorage), כולל 21 משחקים לדוגמה שמגיעים מוכנים מראש.

## הרצה מקומית

```bash
npm install
npm run dev
```

לסריקת ברקוד עם מצלמה נדרש HTTPS או `localhost`, וכן הרשאת מצלמה מהדפדפן.

## בנייה לפרודקשן

```bash
npm run build
npm run preview
```

## טכנולוגיות

React + TypeScript + Vite, React Router, Zustand (עם localStorage persistence), Tailwind CSS, ‎@zxing/browser‎ לסריקת ברקודים.
